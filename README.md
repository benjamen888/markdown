# Markdown 浏览器

一个功能强大的 Chrome 扩展，用于浏览和编辑 Markdown 文件。

## 功能特性

- **多种视图模式**：分屏、编辑、预览、源码
- **实时预览**：编辑时即时渲染 Markdown 内容
- **语法高亮**：支持代码块语法高亮
- **数学公式**：支持 KaTeX 数学公式渲染
- **图表支持**：支持 Mermaid 图表（流程图、时序图、甘特图等）
- **导出功能**：支持导出为 PNG 图片和 PDF 文档
- **文件管理**：支持打开本地文件、文件夹和 URL
- **主题切换**：支持明暗主题切换
- **快捷键**：丰富的快捷键支持

## 环境要求

- Node.js >= 18
- Google Chrome >= 114

## 安装步骤

### 方法一：从 Release 安装（推荐）

1. 访问 [Releases 页面](https://github.com/benjamen888/markdown/releases)
2. 下载最新版本的 `markdown-browser-vX.X.X.zip`
3. 解压下载的 zip 文件
4. 打开 Chrome 浏览器，访问 `chrome://extensions`
5. 开启右上角 **开发者模式**
6. 点击 **加载已解压的扩展程序**
7. 选择解压后的文件夹（包含 `manifest.json` 的文件夹）

### 方法二：从源码构建

1. 克隆仓库：
   ```bash
   git clone https://github.com/benjamen888/markdown.git
   cd markdown
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 构建项目：
   ```bash
   npm run build
   ```

4. 加载到 Chrome：
   - 打开 `chrome://extensions`
   - 开启右上角 **开发者模式**
   - 点击 **加载已解压的扩展程序**
   - 选择项目根目录（包含 `manifest.json` 的文件夹）

## 使用说明

### 打开方式

- **侧边栏模式**：点击 Chrome 工具栏的扩展图标，Markdown 文件会在侧边栏打开
- **全屏模式**：直接访问 `.md` 或 `.markdown` 文件的 URL，扩展会自动渲染

### 视图模式

| 模式 | 说明 |
|------|------|
| 分屏 | 左侧编辑器，右侧预览（默认） |
| 编辑 | 全屏编辑器 |
| 预览 | 全屏预览 |
| 源码 | 显示原始 Markdown 源码 |
| 原始 | 显示页面原始内容（全屏模式） |
| 文件 | 文件浏览器（侧边栏模式） |

### 工具栏按钮

**侧边栏模式：**
- 📁 打开文件
- 📂 打开文件夹
- 🔗 从 URL 打开
- 📄 新建文件
- 💾 保存
- ⬇ 下载
- 🌙 切换主题

**导出按钮（预览区顶部）：**
- 📷 PNG - 导出为 PNG 图片
- 📄 PDF - 导出为 PDF 文档

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + S` | 保存文件 |
| `Ctrl + B` | 加粗文本 |
| `Ctrl + I` | 斜体文本 |
| `Ctrl + K` | 插入链接 |
| `Ctrl + Shift + C` | 插入代码块 |

### 导出功能

#### 导出为 PNG
1. 切换到预览模式或分屏模式
2. 点击预览区顶部的 **📷 PNG** 按钮
3. 图片会自动下载到本地

#### 导出为 PDF
1. 切换到预览模式或分屏模式
2. 点击预览区顶部的 **📄 PDF** 按钮
3. PDF 文件会自动下载到本地（支持多页）

### 文件管理

- **打开本地文件**：点击 📁 按钮，选择本地 Markdown 文件
- **打开文件夹**：点击 📂 按钮，选择文件夹浏览其中的 Markdown 文件
- **从 URL 打开**：点击 🔗 按钮，输入 Markdown 文件的 URL
- **最近文件**：在文件视图中查看最近打开的文件

### 主题切换

点击工具栏的 🌙 按钮切换明暗主题，主题设置会自动保存。

## 支持的 Markdown 特性

- 标题（H1-H6）
- 粗体、斜体、删除线
- 链接、图片
- 有序列表、无序列表
- 任务列表
- 代码块（带语法高亮）
- 表格
- 引用块
- 水平线
- 脚注
- 目录生成
- 数学公式（KaTeX）
- Mermaid 图表
- Emoji

## 更新扩展

修改代码后重新构建并刷新扩展：

```bash
npm run build
```

然后在 `chrome://extensions` 页面点击扩展的刷新按钮。
